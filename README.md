# 🛒 Carrinho de Compras - E-commerce Streetwear

Este projeto consiste na implementação da lógica de um carrinho de compras para um e-commerce de moda *Streetwear*, desenvolvido como parte dos estudos de lógica de programação e estruturas de dados.

## 🚀 Funcionalidades

- **Consulta de Produtos:** Procura automática de produtos na base de dados fictícia pelo seu ID.
- **Validação de Estoque:** Impede a adição de produtos ao carrinho caso a quantidade solicitada exceda o estoque disponível.
- **Gestão do Carrinho:** Permite adicionar novos itens ou atualizar a quantidade de produtos já existentes.
- **Cálculo Automático do Total:** Soma o valor total da compra utilizando métodos avançados de manipulação de arrays (`.reduce()`).
- **Exibição Formatada:** Listagem detalhada dos itens presentes no carrinho com valores formatados em Reais (R$).

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** JavaScript (ES6+) / TypeScript
- **Conceitos aplicados:** Orientação a Objetos (Classes), Métodos de Array (`find`, `reduce`, `forEach`), Condicionais e Manipulação de Objetos.

## 💻 Como Executar o Projeto

1. Copia o código presente no ficheiro `index.js`.
2. Cola num ambiente de execução JavaScript/TypeScript, como:
   - [Coddy Tech Playground](https://coddy.tech/playground/pt/javascript)
   - Node.js (via terminal: `node index.js`)
   - Console do navegador (F12)
